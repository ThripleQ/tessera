## 已知问题 / 必须记住的坑

- **无 GPU 直通**（无 `/dev/dri`），只能软件光栅 llvmpipe。帧时没有参考价值，
  画面与正确性可信。**不要用这台机器的帧率做任何性能结论。**
- **导出包未验证**：运行时 GDScript 编译只在编辑器二进制上验证过。P6 发布前必须用
  真实导出包重跑 ADR 0003 里的探针
- **mod 无沙箱**：`OS.execute` 实测可执行。mod 必须分级，`scripted` 需玩家显式授权
- **房间之间没有门**，走道只是空地；世界是一件直线排列的房间（见 ADR 0004）
- **没有物理**：所有东西都是静态的，玩家相机会穿墙穿地板——它是观察工具，不是角色
- `legacy/cpp-renderer` 构建目录已清理，需要时重新 `cmake -S game -B game/build`
