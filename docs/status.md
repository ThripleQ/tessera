## 已知问题 / 必须记住的坑

- **无 GPU 直通**（无 `/dev/dri`），只有 llvmpipe。帧时没有参考价值，画面可信。
  **不要用这台机器的帧率做任何性能结论。**
- **卡通着色的亮度是标定出来的，不是算出来的**。Compatibility 的 `LIGHT_COLOR` 与
  Forward+ 不同量级，`toon.gdshader` 里的 `light_gain` 是实测值。换渲染器必须重新标定。
- **自检只走到 Plan 层，不实例化玩家**。`player.gd` / `grab.gd` 的运行时错误
  `check.sh` 抓不到，改完必须真的跑一次窗口（或截图探针）。
- **抓取的射线必须从角色胸口发出**，不能从相机。第三人称相机在身后 3.8 米，
  从相机发一条 3 米射线，走到头刚好停在角色后脑勺——第一版就是这么错的，
  表现为"永远抓不到东西"，而且没有任何报错。
- **拉的是质心不是原点**。内容的原点在底面（所有东西都站在自己的原点上），
  把原点拉到胸口的结果是箱子悬在胸口上方浮着。
- **撞击速度必须缓存上一物理帧**。`body_entered` 到达时接触已经解算完，
  此刻 `linear_velocity` 往往已经归零，用它算出来的撞击永远是 0。
- **动态物体不合批**。想加大量可动物体之前，先想清楚提交次数。
- **只有 2 / 13 个组件被引擎实现**。`move` / `ai` / `health` 仍是死数据。
- **导出包未验证**：运行时 GDScript 编译只在编辑器二进制上验证过。P6 前必须重测。
- **mod 无沙箱**：`OS.execute` 实测可执行。`scripted` 级 mod 需玩家显式授权。
- **房间之间没有门**，走道只是空地；世界是一条直线排列的房间（ADR 0004）。
