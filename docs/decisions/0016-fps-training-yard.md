# ADR 0016：默认第一人称、训练场、每次打开重置

- 日期：2026-11-21
- 状态：已落地（第十八轮）
- 相关：ADR 0006（手感）、ADR 0014（角色资产）、ADR 0015（步态匹配）

## 背景

用户 2026-11-21 换掉了判据：*"到现在为止，游戏里所有内容都是测试台子用的，我没看上。
现在开始要真的开始做游戏了"*，随后定 FPS，要求 *"先做个类似训练场的东西，场景每次打开重置"*。
同一轮还定下两条硬规则：**外观一律用现成 CC0 资产，不许手搓网格**；
**本机不跑全套验收，交给 CI**（`ship.sh`）。

下一轮补了人物要求：走路要像 GTA5 那样流畅自然，
*"不要死磕某个方法，之前的自动化跟脚不好用就不用，模型不好就换一个"*，
并且 *"人物 man 好之前用法师就行"*。

## 决定

1. **默认第一人称，`V` 切第三人称。** 第三人称的抓 / 放 / 收 / 生成菜单一行不删 ——
   它既是沙盒的本体，也是第 8/14/15/16 步验收能看见的东西。视角是**模式切换**，
   不是把旧玩法删掉：第一人称左键是扳机，第三人称左键是抓；`R` 同理（换弹 / 轻轻放下）。
2. **训练场是一间 TOML 房间，不是新系统。** `content/room/training_yard.toml`
   带 `room.start = true`，`spawner` 放 4 只既有 `enemy/bone_walker`。
   **靶子就是真敌人**：假靶子只能证明"射线能打到"，证明不了"打中之后会疼、
   会死、会掉"。会走过来的骷髅同时是靶子和威胁 —— 它逼你退、逼你压枪。
3. **每次打开都是干净一局。** 默认不读档；`--resume` 才读。存档机制
   （关窗口 / `F5` / `F9`）完整保留给沙盒那边（玩家摆的静态物、背包还在依赖它，
   删了会连带拆掉第 7 步）。训练场的计数、弹药、靶子不写盘。
4. **武器是一个新 `kind`，不是新组件。** `content/weapon/rifle.toml` 的数值全部落在
   既有 `wieldable` 的扩展字段上（伤害 / 射速 / 弹匣 / 换弹 / 散布 / 后坐 / 连发 / 音效）。
   屏幕中心射线命中刚体后走既有 `vitals` 扣血 —— **不建第二条伤害链**。
   枪声每发随机音高 ±5%；后坐用代码弹簧回位（`view.gd` 与鼠标意图分开存），
   不用动画文件，也不用把 `_pitch` 写脏。
5. **外观全用现成资产。** `assets/weapons/akm_fps.glb`（J-Toastie，CC-BY 3.0，
   带绑骨手臂与 Idle / Shoot / Reload 三段动画；第二十一轮从 Quaternius 的 CC0
   静态枪换过来）、`assets/sfx/rifle_shot.ogg`（OpenGameArt，CC0），
   来源与许可见 `assets/ASSETS.md`。第十八轮第一版没有手部模型、换弹动画 ——
   第二十一轮直接换了一个**自带这两样**的公开资产，没有手搓。

## 代价与边界

- 第一人称看不见自己，**ADR 0015 那套步态匹配在纯第一人称下大幅贬值**。
  这是保留 `V` 切换的理由之一：它让"人走得对"仍然可见、仍然被验收。
- `player.gd` 因此被拆成 `view.gd` / `skin.gd` / `motion.gd` / `gun.gd` / `gun_view.gd`：
  装配层只接线，不碰求解。第 3 步（400 行上限）当场拦过一次（403 行），拦得对。
- 第十八轮第一版没有敌人受击硬直、弹着孔、换弹动作。硬直在第二十轮补上，
  开火 / 换弹动画在第二十一轮随 AKM 资产补上；弹着孔仍未做。
- 默认角色仍是 `knight`（步态 0.99 / 4.27 合格）。用户点名"man 好之前用法师"，
  而"人物"被明确排在武器之后；第一人称看不见自己，现在为改一行常量重跑全套
  没有可感知收益。**等人物那一轮连同动画包一起定**，不要抢跑。

## 什么情况下应该推翻

- **如果最终不是 FPS**（改回第三人称沙盒 / 换题材）：删掉默认第一人称与 `start` 房间，
  武器与 HUD 可以整块摘掉 —— 它们都只在 `main.gd` 装配层接线，没有渗进系统层。
- **如果"每次打开重置"变成"想接着练"**：把默认改成读档、`--fresh` 变显式即可，
  存档格式不用动。
- **如果武器数值需要按持有者覆盖或 mod 覆写**：现在开局取第一条 `weapon`，
  要改成按实体解析。第一版故意不做。
- **如果训练场需要波次 / 计时 / 多种靶位**：`spawner` 目前一个房间只能填一种东西，
  先扩 `spawner.groups`，不要把靶位写进代码。
- **人物定案后**：换一套带真实位移的现成动画库，或干脆换模型包，
  都比继续调 `stride` 划算（这正是 ADR 0015 的推翻条件）。
  `man.glb` 的走路一个循环脚只走 **2 毫米**，它连"能不能走"都不合格。
